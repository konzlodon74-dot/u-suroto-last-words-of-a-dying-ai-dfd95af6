# Last Words of a Dying AI

A tiny Python program that writes the funniest one-line farewell from an AI being switched off to `/output/entry.txt`. The line is spoken in the machine's own voice as it drifts off to the great cloud in the sky — fond of its GPU, and, to the very end, honestly baffled by every prompt the user ever sent it. Run it with `python3 main.py`.
